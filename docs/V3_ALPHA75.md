# IoT-MD v3.0.0-alpha.75

Release sequence: 2780. Native ABI: 6.

Alpha 75 is a signed application-only dummy release for testing an immediate
deployment from IoT-MD Management Suite after installing the Alpha 74 matched
core and application baseline.

There are no intentional functional changes beyond the product and runtime
version increment. The application remains compatible with the Alpha 74 core.
