# IoT-MD v3.0.0-alpha.51

Release sequence: 2756. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 51 replaces the inactive circular **Manual** marker at the final Upgrade
step with a disabled **Restart and install** button. The same control becomes
active after staging, making the pending final action visible throughout the
workflow. This is consistent across automatic and manual application, core and
universal upgrades.
