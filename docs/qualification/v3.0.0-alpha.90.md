# v3.0.0-alpha.90 backup-preview request-bound regression

## Automated evidence

- The complete-backup preview route accepts the bounded 384 KiB encrypted
  envelope allowance independently of the retained core configuration.
- Query parameters do not bypass route recognition.
- Ordinary configuration and command routes retain the configured lower body
  limit.
- Device API and MicroPython compatibility tests pass.

## Field verification

1. Upgrade an Alpha 89 device to Alpha 90 without changing its native core.
2. In Management Suite Recovery points, expand a complete configuration backup
   and select **Preview restore**.
3. Confirm the preview reports the change count instead of `HTTP body exceeds
   the configured limit`.
4. Confirm ordinary oversized Device API commands remain rejected.
