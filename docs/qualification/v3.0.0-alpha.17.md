# IoT-MD v3.0.0-alpha.17 qualification

Alpha 17 uses release sequence `2722` and native platform ABI 6.

## Required observations

1. Install the signed universal artifact and verify both displayed component
   versions finish on Alpha 17 and remain there after restart and power cycle.
2. Select the universal artifact and confirm the inline file guidance
   disappears. During staging, confirm the prominent label reads **Current
   task:** followed by the operation without a duplicate `Step n of 8` label.
3. After universal verification, confirm the same eight-stage vertical
   workflow remains visible, with its first seven stages complete and
   **Activate and reboot** active.
4. Select application and core recovery artifacts in turn and confirm each
   previews and retains its own detailed workflow.
5. In the Management Suite 2.2.3 release inventory, promote Alpha 17 to Alpha.
   Select Alpha in the device's automatic-upgrade settings, check for an
   upgrade and confirm the signed `/alpha/latest.json` catalog is accepted.
6. Repeat Alpha 13's universal upgrade, rollback and interrupted-power checks.

No additional greenfield feature gate is introduced by this release. Active-v3
promotion remains blocked until every release-bound gate has passing
hardware-in-the-loop evidence.
