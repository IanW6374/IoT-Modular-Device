# IoT-MD v3.0.0-alpha.15 qualification

Alpha 15 uses release sequence `2720` and native platform ABI 6.

## Required observations

1. Install the signed universal artifact and verify both displayed component
   versions finish on Alpha 15 and remain there after restart and power cycle.
2. Select each manual artifact type and start staging. Confirm the filename is
   then hidden, only one current-task progress area is present, the vertical
   workflow matches the file type, and Cancel returns to file selection.
3. Confirm Cancel and **Upload and stage**, or Cancel and **Activate and
   reboot**, remain aligned at the lower right of the manual-upgrade section.
4. Before upgrading, calibrate a Grove AC Voltage module using a trusted meter.
   Record the multiplier shown in Module Diagnostics and verify it is unchanged
   after normal restart, power cycle, and the universal upgrade.
5. Use Tab to focus each linked overview metric. Confirm the entire tile has a
   visible focus ring and opens its destination; its status text does not gain
   an independent colour treatment.
6. Repeat Alpha 13's universal upgrade, rollback and interrupted-power checks.

Active-v3 promotion remains blocked until every release-bound gate has passing
hardware-in-the-loop evidence.
