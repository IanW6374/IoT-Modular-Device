# Alpha 42 application upgrade-flow test

Alpha 42 uses release sequence `2747` and native platform ABI 6.

1. Start from a healthy, confirmed Alpha 41 application.
2. Stage the signed Alpha 42 `.iotapp` through Manual upgrade.
3. Confirm file selection, live progress and the Verified badge remain aligned
   with their respective chart steps.
4. Leave the Upgrade page and return; confirm Alpha 42 is still staged and the
   running Alpha 41 application has not restarted.
5. Select **Restart and install** and verify Alpha 42 reaches healthy
   confirmation without rollback.
6. Confirm Alpha 41 remains available as the retained application rollback.
