# Alpha 41 consolidated Upgrade workflow test

Alpha 41 uses release sequence `2746` and native platform ABI 6.

1. Open Manual upgrade and confirm the file selection is centered beneath
   **Select signed file**, with no duplicate current-task row or divider.
2. Start an upload and confirm progress is shown only in the applicable chart
   step, with no disabled **Working…** button.
3. Select **Discard** during upload and confirm the view resets without a page
   refresh and the resumable server upload is removed.
4. Complete staging and confirm the **Verified** badge is centered beneath
   **Verify and stage**.
5. Leave and reopen the page; confirm the release remains staged and no restart
   occurs until **Restart and install** is selected.
6. Confirm Automatic selection is centered beneath **Select version**, and the
   final actions for install and rollback retain their concise labels.
