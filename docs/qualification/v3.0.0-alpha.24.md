# IoT-MD v3.0.0-alpha.24 storage-handle recovery test

Alpha 24 uses release sequence `2729` and native platform ABI 6.

1. Install `universal-3.0.0-alpha.24.iotuni`; do not install only the
   application component.
2. Confirm Overview reports both Application version and Core version as
   `3.0.0-alpha.24`.
3. Open **Maintenance > Release qualification** and confirm the recorder is
   available and no storage-handle warning is displayed.
4. Refresh and revisit Release qualification at least ten times. Confirm the
   recorder remains available and the counters continue from persisted state.
5. Restart the device from **Maintenance > Power & reset**. After sign-in,
   confirm Release qualification remains available and campaign evidence has
   not been reset.
6. Perform one additional universal upgrade or application restart during the
   campaign, then repeat steps 2–5. Confirm reopening the three qualification
   namespaces does not consume additional native handles.
7. If the recorder reports another initialization error, capture that exact
   first error and the Device log. It should no longer be replaced by
   `storage handle limit reached`.
