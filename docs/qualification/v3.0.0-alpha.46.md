# Alpha 46 application upgrade-flow test

Alpha 46 uses release sequence `2751` and native platform ABI 6.

1. Start from a healthy, confirmed Alpha 45 application.
2. Choose the signed Alpha 46 `.iotapp` and confirm the recovery-file guidance
   disappears.
3. Select **Stage upgrade** and confirm preparation and upload begin.
4. Confirm verification transitions in place to the staged chart.
5. Select **Restart and install** and verify Alpha 46 reaches healthy
   confirmation without rollback.
6. Confirm Alpha 45 remains available as the retained application rollback.
