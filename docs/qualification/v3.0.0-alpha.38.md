# Alpha 38 startup and Upgrade UI regression test

Alpha 38 uses release sequence `2743` and native platform ABI 6.

1. Install the signed Alpha 38 application from a confirmed Alpha 36 device and
   verify the trial reaches healthy confirmation without a `logOutput` startup
   exception or rollback.
2. Open **Maintenance > Upgrade** with Automatic and Manual available. Add a
   staged release and retained rollback slot; confirm every method choice keeps
   the same desktop width as the original choices.
3. Hover and keyboard-focus each method choice. Confirm the focus outline is
   visible and no text inside the choice becomes underlined.
4. Repeat on a narrow display and confirm the choices use one full-width column.
5. Stage application, core and universal files in turn. Confirm every activation
   button is labelled **Restart and install**, without a type or version suffix.
6. Confirm the Alpha 37 qualification status, controlled evidence and audit
   history remain available after the upgrade.
