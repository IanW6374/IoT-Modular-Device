# Alpha 44 application upgrade-flow test

Alpha 44 uses release sequence `2749` and native platform ABI 6.

1. Start from a healthy, confirmed Alpha 43 application.
2. Select the signed Alpha 44 `.iotapp` and confirm its filename is prominent.
3. Stage the release and confirm verification changes the existing workflow to
   the staged state without a page reload.
4. Leave and reopen Upgrade and confirm the same staged chart is retained.
5. Select **Restart and install** and verify Alpha 44 reaches healthy
   confirmation without rollback.
6. Confirm Alpha 43 remains available as the retained application rollback.
