# Alpha 47 cross-method Upgrade format test

Alpha 47 uses release sequence `2752` and native platform ABI 6.

1. Confirm Manual keeps file selection beneath **Select signed file** and starts
   preparation when **Stage upgrade** is selected.
2. Confirm Automatic keeps the version, **Stage upgrade**, and channel check
   beneath **Select version**.
3. During an automatic download, confirm the selected release remains beneath
   **Select version** and progress appears only in the chart.
4. Confirm Staged keeps selection, Discard, Verified and restart actions beneath
   their corresponding steps.
5. Confirm Rollback displays its retained application beneath **Previous
   application retained** and its restart action in the final step.
6. Repeat applicable checks for application, core and universal releases.
