1. Start from a healthy, confirmed Alpha 47 application.
2. Stage the signed Alpha 48 `.iotapp` through Manual upgrade.
3. Confirm selected-release information and actions remain attached to the

5. Select **Restart and install** and verify Alpha 48 reaches healthy
