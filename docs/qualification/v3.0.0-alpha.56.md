# Alpha 56 Device API POST/TLS regression test

Alpha 56 uses release sequence `2761` and native platform ABI 6.

Status: **failed on device**. The POST still ended with an unexpected EOF
because the header parser retained a 512-byte read-ahead. Superseded by Alpha
57.

1. Upgrade the application to Alpha 56 and confirm a healthy startup while the
   Alpha 52 native core remains installed.
2. Using the enrolled Management Suite client identity, confirm
   `GET /api/v2/fleet` returns HTTP 200.
3. POST `{}` to `/api/v2/fleet/policy` and confirm HTTP 400 JSON is returned;
   the connection must not close without a response.
4. Push a signed policy from Management Suite 2.2.10 or later.
5. Confirm the Suite reports success and `GET /api/v2/fleet` shows a non-zero
   `policy_sequence` with the policy targeting the discovered immutable device
   identity.
6. Repeat a qualification-event POST and confirm it returns a bounded API
   response rather than EOF.
