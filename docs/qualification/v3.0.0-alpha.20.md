# IoT-MD v3.0.0-alpha.20 qualification

Alpha 20 uses release sequence `2725` and native platform ABI 6.

## Upgrade and evidence continuity

1. Install the signed universal artifact and verify application and core both
   report Alpha 20 after activation and another normal restart.
2. Before upgrading again, note the paired-upgrade, certificate-renewal,
   power-recovery and controlled-validation counters. Confirm they remain after
   a newer release begins while soak, health, storage and canary observations
   start for that new release.
3. Confirm a successful paired universal activation increments the persistent
   paired-upgrade counter. An intentional rollback may be recorded without
   failing that gate; a deliberately invalid update must record a failure.
4. Disconnect the MQTT broker during boot. Confirm the portal returns in a
   degraded state with an amber Status LED, then restore the broker and verify
   MQTT reconnects without restarting the device or failing the Health gate.

## Accounts and sessions

5. Create a non-administrator account with a short test timeout and forced
   password change. Confirm its first session can only change the password or
   sign out, then gains its configured role after successful replacement.
6. Enter an incorrect password up to the configured retry limit, confirm the
   account locks persistently, then use another administrator to unlock it.
7. Leave a test session inactive beyond its own timeout and confirm the next
   navigation shows the signed-out login notice and clears the session cookie.

## Certificates and presentation

8. On a device using a managed enrollment method, select **Renew now**, confirm
   the operation completes, the presented identity reloads and the renewal
   qualification counter increments. Confirm manual enrollment offers no force
   renewal action.
9. Inspect every certificate tab with issuer/subject values containing an
   apostrophe and confirm no literal `&#39;` text appears.
10. Confirm Portal users displays existing users and the new-user form as equal
    fixed-width cards. Confirm the Status menu LED follows running, degraded and
    failed device states and remains usable with keyboard and screen-reader
    navigation.

Repeat Alpha 19's physical power-cycle checks and Alpha 13's paired rollback
and interrupted-power checks before accepting this build as a promotion
candidate.
