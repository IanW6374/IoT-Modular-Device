# IoT-MD v3.0.0-alpha.21 qualification

Alpha 21 uses release sequence `2726` and native platform ABI 6.

## Upgrade and portal regression

1. Install the signed universal artifact and confirm both application and core
   report Alpha 21 after activation and one further normal restart.
2. Open Overview, Upgrades, Portal users and Device log. Confirm none returns
   **Request could not be completed** and no undefined request/session name is
   recorded in Device log.
3. Let a session expire, then navigate or allow a live refresh to run. Confirm
   the signed-out page is shown and no `cookie_session_id` failure is recorded.
4. Check the Alpha automatic channel. Confirm the offer says **Paired upgrade
   (core + application)**, its **Download and stage** action is right-aligned,
   and the task page identifies the paired operation.
5. Stage the automatic release and confirm its persistent state appears under
   **Upgrade process**, with **Paired upgrade — Core 1 of 2** before the first
   activation and Application 2 of 2 after the core is confirmed.
6. Repeat a manual universal upload and verify its eight-stage workflow,
   activation and reboot remain functional.

Repeat Alpha 20's account, certificate-renewal, MQTT recovery and qualification
campaign checks before accepting this build as a promotion candidate.
