# IoT-MD v3.0.0-alpha.19 qualification

Alpha 19 uses release sequence `2724` and native platform ABI 6.

## Required observations

1. Install the signed universal artifact and verify the application and core
   versions both finish on Alpha 19 and remain there after a normal restart.
2. Open **Maintenance > Release qualification**, record the current
   power-recovery counter, and confirm its source is **Device observed**.
3. Physically remove and restore device power with the configured access point
   available. Wait until the portal reports a green LED and healthy `running`.
4. Confirm the power-recovery counter increased by exactly one and Health
   history contains `power_recovery_qualified` for that boot.
5. Repeat the physical power cycle twice. Each healthy recovery must add one
   result; refreshing the portal or waiting for monitoring samples must not add
   another.
6. Use the portal restart control and confirm its software reset does not
   increment the power-recovery counter.
7. Confirm one `boot` event exists for each real restart. Treat the timestamp
   change from the year 2000 to wall-clock time as NTP synchronisation, not a
   second boot.
8. Repeat Alpha 18's Wi-Fi retry and qualification-history checks and Alpha
   13's universal rollback and interrupted-power checks.

No new greenfield mechanism gate is introduced by this release. Active-v3
promotion remains blocked until all release-bound gates have passing evidence.
