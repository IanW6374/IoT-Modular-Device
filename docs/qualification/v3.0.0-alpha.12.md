Alpha 12 uses release sequence `2717` and native platform ABI 6.

## Required observations

1. Install the universal artifact from the recovered Alpha 10/Alpha 9 pair and
   verify that both displayed versions finish on Alpha 12.
2. Verify update history records the `runtime-healthy`, `platform-confirmed`,
   `platform-metadata` and `runtime-committed` boundaries on success.
3. Interrupt power before native confirmation. The previous core and previous
   application must boot without entering amber recovery.
4. Interrupt power after native confirmation but before application commit.
   The new core must finish the idempotent application commit on the next boot.
5. Force native confirmation to fail. Verify `confirmation_failed` retains the
   exact error and the terminal pair contains no mixed versions.
6. Leave a stale lower-sequence native trial journal, then install Alpha 12.
   The newer signed pair must replace it without reporting another pending
   universal update.
7. Repeat Alpha 11's upload UI, login, network, migration, cutover, transport,
   identity, fleet, driver, recovery and soak checks.

HIL evidence.
