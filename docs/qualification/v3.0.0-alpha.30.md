# IoT-MD v3.0.0-alpha.30 power-cycle and portal resilience test

Alpha 30 uses release sequence `2735` and native platform ABI 6.

1. From Alpha 29, select the Alpha 30 universal release through either the
   automatic or manual path. Confirm both use the same type-aware installation
   page and that Overview reports Application and Core version
   `3.0.0-alpha.30` after confirmation.
2. Open **Maintenance > Release qualification**, refresh it several times and
   confirm the recorder remains available and its counters do not reset.
3. Remove device power for at least five seconds, restore it and allow the
   device to return without USB interaction. Confirm the status LED becomes
   green and the sign-in page is available.
4. Sign in and open Overview, Release qualification and Device log. Confirm no
   generic request-failure page or NVS error `4357` is produced.
5. Repeat the power cycle twice. Confirm the power-recovery counter advances
   once for each completed healthy recovery and the paired release remains
   Alpha 30.
6. In **Maintenance > Upgrade**, confirm there is no separate **Install
   upgrade** menu item and **Check for upgrades** is aligned to the right of its
   Automatic upgrade section.
7. In **Maintenance > Users**, confirm the only enabled administrator cannot be
   disabled or demoted and its explanation appears as control help rather than
   permanent warning text.
