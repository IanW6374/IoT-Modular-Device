# IoT-MD v3.0.0-alpha.23 automatic-upgrade test

Alpha 23 uses release sequence `2728` and native platform ABI 6. It validates
the automatic universal path from a device running Alpha 22 and includes the
focused portal corrections recorded during Alpha 22 testing.

1. Install IoT MD Management Suite 2.2.6 or later.
2. Synchronize the Alpha 23 GitHub release and promote it to Alpha.
3. From an Alpha 22 device, check the Alpha channel under **Maintenance >
   Upgrades**.
4. Confirm the offer is **Universal upgrade 3.0.0-alpha.23**, not an individual
   application or core release.
5. Select **Download and stage**. Confirm the progress workflow is the same as
   a manual universal upload and both components reach ready state.
6. Activate the universal upgrade and confirm the device restarts with both
   Application version and Core version showing `3.0.0-alpha.23`.
7. Restart once more and confirm both versions remain paired and healthy.
8. Check recent upgrade history and qualification evidence for a successful
   paired upgrade; no component-only fallback should be recorded.

## Portal regression checks

1. After activation, leave the restart page open. Confirm it returns to the
   sign-in page automatically without selecting **Open login page**.
2. Confirm Maintenance displays **Users**, and that the existing/new user
   fields, checkboxes and action buttons are vertically aligned.
3. Confirm all labels and values in the Overview device-status row align,
   including labels that wrap over two lines.
4. Set a test user's inactive-session timeout to five minutes, remain idle and
   confirm the browser opens the signed-out login page when the timeout expires
   without requiring another navigation.
5. Under **Maintenance > Certificates > Device certificates**, confirm the
   current managed enrollment method and **Renew now** are visible. Exercise the
   action only when a real renewal endpoint is available.
6. Confirm every installed item under **CA & signing trust**, including the
   Management Suite signing key, places **Remove trust** at the bottom-right of
   an equal-height card.
7. Delete an unpromoted test release from GitHub, synchronize releases in
   Management Suite 2.2.6 and confirm its inventory card and local release files
   are removed.
