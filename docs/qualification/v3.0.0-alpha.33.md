# IoT-MD v3.0.0-alpha.33 upgrade workflow test

Alpha 33 uses release sequence `2738` and native platform ABI 6. Multi-version
selection requires IoT MD Management Suite 2.2.7; the single newest release
remains usable with earlier Suite versions.

## Focused device test

1. Install Management Suite 2.2.7 and promote at least two releases newer than
   the device to Alpha. Confirm `/alpha/latest.json` names the newest and
   `/alpha/versions.json` contains both versions.
2. On the device, select **Maintenance > Upgrade**, check for upgrades and open
   the installation workflow. Confirm Automatic and Manual are presented as
   explicit methods.
3. Select Automatic. Confirm its version selector lists only newer compatible
   releases, newest first, and identifies each as Universal, Application or
   Core firmware.
4. Change the selected version and confirm the horizontal milestone names
   immediately match its artifact type. Each task name must appear above an
   aligned circular percentage indicator.
5. Return to method selection and select Manual. Confirm the version selector
   is replaced by the signed-file picker and that choosing each supported file
   extension produces the correct stage list.
6. Complete an automatic universal upgrade. Confirm progress survives page
   refresh, staging leads to the normal restart action, and both application
   and core report `3.0.0-alpha.33` after confirmation.
7. At a narrow browser width, confirm the same milestones become a readable
   vertical track without clipped labels or controls.
8. Repeat the existing paired rollback, power-interruption, certificate renewal
   and qualification checks before promoting beyond Alpha.
