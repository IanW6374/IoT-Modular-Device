# Alpha 59 portable API error-response test

Alpha 59 uses release sequence `2764` and native platform ABI 6.

Status: **passed on device**. Alpha 59 returned a bounded JSON policy error in
place of the previous EOF, exposing the independent policy epoch mismatch
addressed by Alpha 60.

1. Upgrade the application to Alpha 59 and confirm a healthy startup while the
   Alpha 52 native core remains installed.
2. Confirm `GET /api/v2/device` reports Alpha 59 and release sequence 2764.
3. POST `{}` to `/api/v2/fleet/policy` and confirm HTTP 400 JSON reports
   `unsupported fleet policy format`; the connection must not end with EOF.
4. Push a signed policy from Management Suite 2.2.10 or later.
5. Confirm the Suite reports success, or use its returned HTTP JSON error to
   correct any remaining policy validation issue.
6. Confirm `GET /api/v2/fleet` shows a non-zero `policy_sequence` after the
   valid policy succeeds.
