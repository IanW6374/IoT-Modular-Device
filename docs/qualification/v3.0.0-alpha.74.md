# v3.0.0-alpha.74 manual universal activation regression

## Automated evidence

- Manual universal activation is allowed when a fleet policy exists outside
  its maintenance window.
- Managed activation remains blocked outside the window and allowed inside it.
- Managed activation remains allowed when no fleet policy is installed.
- The portal sends an explicit internal manual-activation context rather than
  accepting a client-controlled override field.
- The full host, MicroPython compatibility and secure ESP32-S3 build suites
  must pass for the release commit.

## Field verification

1. Stage the Alpha 74 universal bundle while a fleet policy exists outside its
   maintenance window.
2. Select **Restart and install** in the device portal and confirm activation
   proceeds without the maintenance-window error.
3. Confirm both application and core report `3.0.0-alpha.74` after restart.
4. Submit a managed activation outside the window and confirm it remains
   pending until the window opens.
