# Alpha 39 Upgrade method and restart-step test

Alpha 39 uses release sequence `2744` and native platform ABI 6.

1. Open **Maintenance > Upgrade** with only Automatic and Manual available.
   Confirm each choice occupies one quarter of the desktop method row—the width
   it would have when all four methods are present.
2. Make Staged and Rollback available and confirm all four choices have equal
   widths. At medium and small viewport widths, confirm the layout changes to
   two and one columns respectively.
3. Stage application, core and universal artifacts. Confirm the final graph step
   has no percentage and contains **Restart and install** rather than showing a
   separate activation button.
4. Open Rollback and confirm its final graph step contains **Restart and
   rollback**, without a version suffix or a separate action button.
5. Keyboard-focus every method choice and final action. Confirm focus remains
   visible, no choice text is underlined, and activation still requires an
   explicit button press.
6. Install Alpha 39 and confirm healthy startup, upgrade confirmation and
   retained rollback state.
