# IoT-MD v3.0.0-alpha.14 qualification

Alpha 14 uses release sequence `2719` and native platform ABI 6.

## Required observations

1. Install the signed universal artifact and verify both displayed component
   versions finish on Alpha 14 and remain there after restart and power cycle.
2. Before upload, select one `.iotapp`, `.iotcore` and `.iotuni` file in turn.
   Confirm the vertical workflow immediately changes to the matching component
   or paired sequence. Confirm the action says **Upload and stage**.
3. Open each overview metric that has a meaningful destination and confirm it
   reaches the expected settings, diagnostics, health, upgrade or qualification
   page with keyboard and pointer input.
4. Inspect all four certificate pages with installed, missing, expiring,
   expired and invalid examples; confirm the same state always uses the same
   badge color.
5. Verify Power & reset actions remain distinct, runtime health is grouped into
   cards, and portal-user roles appear only in their editable select control.
6. Repeat Alpha 13's universal upgrade, rollback and interrupted-power checks.

Active-v3 promotion remains blocked until every release-bound gate has passing
hardware-in-the-loop evidence.
