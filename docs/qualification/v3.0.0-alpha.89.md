# v3.0.0-alpha.89 managed encrypted backup and restore

## Automated evidence

- Only a client with `configuration:write` can create or restore a backup.
- Complete configuration encryption is performed by the device before the API
  returns the envelope.
- Restore preview and application are separate operations connected by the
  existing short-lived random token.
- The API request bound accommodates the maximum encrypted envelope without
  becoming unbounded.
- Device API, MicroPython compatibility and architecture checks pass.

## Field verification

1. Create a manual recovery point from Management and confirm it is listed as
   encrypted without displaying a password or backup contents.
2. Change a harmless device setting and request a restore preview.
3. Confirm the preview reports the changed setting without exposing its secret
   value.
4. Apply the restore, restart, and confirm the original setting is restored.
5. Repeat using a compatible spare device and verify the cross-device warning,
   typed confirmation, certificate names and network rollback behavior.
