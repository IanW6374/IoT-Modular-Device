# v3.0.0-alpha.95 managed backup responsiveness regression

## Automated evidence

- Product metadata identifies `3.0.0-alpha.95` with release sequence `2800`.
- Runtime generation `192` is newer than Alpha 94 generation `191`.
- Management-derived keys produce and decrypt the unchanged version-2 backup
  envelope.
- Client disconnects after API work are handled without a second failing TLS
  response.

## Field verification

1. Upgrade a device to Alpha 95 and refresh IoT-MD Management.
2. Start a complete encrypted backup from **Actions / Back up**.
3. Open the device portal while the backup is running and confirm its TLS
   handshake and page response remain available.
4. Confirm the recovery point reaches **Stored** and can be previewed.
5. Preview a recovery point created before Alpha 95 and confirm its settings
   remain readable.
