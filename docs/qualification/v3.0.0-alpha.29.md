# IoT-MD v3.0.0-alpha.29 unified upgrade workflow test

Alpha 29 uses release sequence `2734` and native platform ABI 6.

1. If the device runs Alpha 26 or Alpha 27, install and activate
   `application-3.0.0-alpha.29.iotapp` first. Confirm the application trial and
   then continue with the universal package. A device on Alpha 28 may start
   with the universal package directly.
2. Open **Maintenance > Upgrades > Available upgrades**. Confirm the page
   presents Summary, Upgrade already staged, Rollback, Automatic upgrade and
   Manual upgrade in that order, omitting actions that are not currently
   applicable.
3. Select the Alpha 29 automatic universal release. Confirm **Install upgrade**
   identifies it as universal and shows the paired steps, but performs no
   download or staging before **Initiate upgrade** is selected.
4. Initiate the automatic path. Confirm progress remains in the normal portal
   shell, completes both signed components and returns to the same Install
   upgrade page with **Restart and install** available.
5. Discard the staged release in a controlled test if necessary, select
   `universal-3.0.0-alpha.29.iotuni` manually and confirm the same paired steps,
   staged state and final action are used.
6. Restart and install. Confirm Overview reports Application and Core version
   `3.0.0-alpha.29`, the status LED is green and the portal returns normally.
7. Restart and power-cycle once. Confirm the paired release remains selected,
   Release qualification remains available and no storage-capacity rejection
   or duplicate upgrade workflow appears.
