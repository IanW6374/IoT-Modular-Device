# Alpha 51 disabled restart-control test

Alpha 51 uses release sequence `2756` and native platform ABI 6.

1. Open Manual upgrade before selecting a file and confirm the final step shows
   a disabled grey **Restart and install** button rather than a Manual circle.
2. Select application, core and universal files in turn and confirm each
   type-specific workflow retains the same disabled final control.
3. Open Automatic upgrade, change among available application, core and
   universal releases, and confirm the final control remains consistent.
4. Stage a signed release and confirm the disabled control is replaced in place
   by the active **Restart and install** button.
5. Confirm the active control restarts and installs the staged release and the
   previous application remains available for rollback.
