- The signed application package uses release sequence 2788.

## Field verification

1. Open **Maintenance / Certificates / API client trust**.
2. Confirm there is one **API caller certificate** option rather than separate
   certificate types for each caller role.
3. Enrol a client using each relevant permission preset and confirm the scopes
   displayed on its trust card match the selection.
4. Select **Custom**, choose multiple scopes and confirm those exact scopes are
   retained after enrolment.
5. Edit an enrolled client's scopes and confirm the fingerprint remains a
   single trust record.
6. Push a profile containing automatic-update settings and an MQTT or Wi-Fi
   password; confirm the device applies the settings and never reports the
   secret value through its API or portal.
