# v3.0.0-alpha.96 legacy backup retry regression

## Automated evidence

- Product metadata identifies `3.0.0-alpha.96` with release sequence `2801`.
- Runtime generation `193` is newer than Alpha 95 generation `192`.
- A legacy remote password-only backup request is rejected before key
  derivation, while local string-password backup calls remain supported.

## Field verification

1. Leave a backup retry pending in Management 2.7.2.
2. Install Alpha 96 over USB and allow the device to boot.
3. Confirm the legacy retry fails with the Management 2.7.3 requirement and
   the device portal remains responsive.
4. Upgrade Management to 2.7.3 and retry the backup.
5. Confirm the backup reaches **Stored** and the device portal remains usable.
