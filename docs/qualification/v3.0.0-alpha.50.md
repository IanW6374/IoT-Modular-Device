# Alpha 50 application upgrade-flow test

Alpha 50 uses release sequence `2755` and native platform ABI 6.

1. Start from a healthy, confirmed Alpha 49 application.
2. Stage the signed Alpha 50 `.iotapp` and confirm Discard remains bottom-right
   during selection, upload and the staged state.
3. Confirm verification completion is shown by the progress step without a
   separate badge.
4. Select **Restart and install** and verify Alpha 50 reaches healthy
   confirmation without rollback.
5. Confirm Alpha 49 remains available as the retained application rollback.
