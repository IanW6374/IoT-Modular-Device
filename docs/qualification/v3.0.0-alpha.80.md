# v3.0.0-alpha.80 managed schedule projection

## Automated evidence

- The authenticated configuration API reports automatic-update cadence, time,
  weekday, automatic download and automatic activation.
- The application requires core API 11 and uses release sequence 2785.
- Device API, architecture and complete repository tests pass.

## Field verification

1. Configure a daily or weekly automatic-update schedule on the device.
2. Refresh the device in IoT-MD Management Suite 2.3.0 and confirm the Devices
   page shows the same schedule.
3. Create a deployment using **Use device schedule** and confirm it stages
   immediately.
4. Confirm activation remains scheduled for the device's configured slot and
   the deployment and audit timelines retain the transitions.
5. Repeat with **Install now** and confirm the portal identifies the action as
   an administrator override.
