# IoT-MD v3.0.0-alpha.16 qualification

Alpha 16 uses release sequence `2721` and native platform ABI 6.

## Required observations

1. Install the signed universal artifact and verify both displayed component
   versions finish on Alpha 16 and remain there after restart and power cycle.
2. Calibrate a Grove AC Voltage module. Confirm the diagnostics page reports
   success, displays the updated multiplier and remains fully styled. Verify
   the value persists after restart and power cycle.
3. Upload an older or otherwise rejected signed upgrade. Confirm the task reads
   **Failed**, the rejected file is cleared, neither button remains in a
   working state, and a new file can be chosen without pressing Cancel.
4. Use pointer and keyboard focus on linked Overview metrics. Confirm only the
   tile outline/elevation/focus ring changes and no text is underlined.
5. If an unexpected authenticated portal request failure is induced, confirm a
   styled error page offers **Go back** and **Open device log**, and the log
   displays the cause as text rather than interpreting it as HTML.
6. Repeat Alpha 13's universal upgrade, rollback and interrupted-power checks.

No additional greenfield feature gate is introduced by this release. Active-v3
promotion remains blocked until every release-bound gate has passing
hardware-in-the-loop evidence.
