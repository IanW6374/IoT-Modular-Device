# IoT-MD v3.0.0-alpha.27 qualification storage and workflow test

Alpha 27 uses release sequence `2732` and native platform ABI 6.

1. Install `universal-3.0.0-alpha.27.iotuni` and activate it. Confirm Overview
   reports both Application version and Core version as `3.0.0-alpha.27`.
2. Open **Maintenance > Release qualification**. Confirm the recorder is
   available and error `4357` is absent.
3. Leave the qualification page active long enough for several observation
   updates, revisit it, and confirm counters and cross-release evidence remain
   available rather than failing as snapshots are replaced.
4. Restart and power-cycle the device. Confirm it returns with a green status
   LED, the portal is reachable and the qualification recorder still opens.
5. Open **Maintenance > Users** with only one enabled administrator. Confirm
   its Role and Enabled controls are locked and the protection explanation is
   visible. Add and enable a second administrator, then confirm both controls
   become editable.
6. Confirm **Maintenance > Upgrades** expands to **Available upgrades**,
   **Install upgrade**, and **Settings**, in that order.
7. Confirm **Settings** contains the channel, schedule, automatic download and
   automatic activation controls, and that these controls no longer appear on
   **Available upgrades**.
8. Stage a signed local test file and confirm the portal moves to **Install
   upgrade**. Discard it and confirm the portal returns to **Available
   upgrades**.
9. When a later signed release is available, use **Download and stage** and
   confirm the automatic path also finishes on **Install upgrade**.
