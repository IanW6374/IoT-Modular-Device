# Alpha 54 discard-and-retry regression test

Alpha 54 uses release sequence `2759` and native platform ABI 6.

Status: **host regression passed; awaiting device evidence**.

## Procedure

1. Start a manual application upgrade and select **Discard** while verification
   is in progress.
2. Wait for the workflow to return to release selection, then stage Alpha 54
   without refreshing the browser or restarting the device.
3. Confirm the final **Restart and install** control becomes active and the
   staged workflow remains visible.
4. Discard that fully staged release. Stage Alpha 54 again and confirm the same
   active restart control is presented.
5. Restart and install. Confirm application version `3.0.0-alpha.54`, release
   sequence `2759`, healthy startup and retention of the Alpha 52 application
   for rollback.
6. Repeat the discard-and-retry exercise for a universal artifact before using
   the result as paired-update qualification evidence.

The broader Alpha 53 qualification requirements remain applicable. Release-
bound evidence must be collected against the final installed sequence.
