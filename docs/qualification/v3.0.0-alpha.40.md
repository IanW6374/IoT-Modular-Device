# Alpha 40 application upgrade-flow test

Alpha 40 uses release sequence `2745` and native platform ABI 6.

1. Start from a healthy, confirmed Alpha 39 application.
2. Stage the signed Alpha 40 `.iotapp` through Manual upgrade.
3. Confirm the final progress step contains **Restart and install** without a
   percentage or separate activation button.
4. Restart and verify Alpha 40 reaches healthy confirmation without rollback.
5. Confirm Alpha 39 remains available as the retained application rollback.
6. Open Rollback and verify its final step contains **Restart and rollback**
   without a version suffix.
