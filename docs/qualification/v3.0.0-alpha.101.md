# Alpha 101 description and portal regression checks

1. Install the Alpha 101 universal update and confirm both version fields show
   Alpha 101 after trial confirmation.
2. Enroll with a blank Management description and confirm the saved device
   description is discovered. Edit it in Management and confirm IoT-MD reports
   the new value without a restart-required notice.
3. Clear the description and confirm it remains empty after a fresh inventory
   poll and after a device restart.
4. Remove API-write permission and try another description edit. Confirm the
   save fails visibly, retains the edit and leaves the device value unchanged.
5. Check device, Management, Certificate Authority and Syslog forms at desktop
   and phone widths. Inputs and single-line selects should align; text areas
   and multi-select controls must remain usable.

These are hardware acceptance steps, not claims of completed hardware testing.
