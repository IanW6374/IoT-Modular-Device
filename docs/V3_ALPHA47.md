# IoT-MD v3.0.0-alpha.47

Release sequence: 2752. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 47 applies the chart-attached presentation consistently to Automatic,
Manual, Staged and Rollback upgrades. Selection, checking, retained-version
details, verification and final actions remain attached to their relevant
steps. Normal task text is no longer duplicated below automatic progress;
below-chart status is reserved for actionable failures.
