# IoT-MD v3.0.0-alpha.52

Release sequence: 2757. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 52 is the final alpha qualification candidate and exercises the signed
upgrade workflow from Alpha 51. It contains no intentional functional changes
beyond the product and runtime version increment and retains the disabled
**Restart and install** control until staging completes.

The release includes matching production-secure application, core and
firmware-first universal bundles. Their manifests are signed with the same
release key, bind version `3.0.0-alpha.52` to sequence `2757`, and contain the
same source revision. Host simulation is regression evidence only; promotion
still requires the physical campaign in the
[Alpha 52 qualification plan](qualification/v3.0.0-alpha.52.md).
