# IoT-MD v3.0.0-alpha.94

Alpha 94 is an application-only deployment test release. Unlike Alpha 93, it
advances both the product version and the application runtime generation so a
device on Alpha 92 or Alpha 93 recognises it as a newer compatible application.

- Product version: `3.0.0-alpha.94`
- Release sequence: `2799`
- Application runtime generation: `191`
- Required core API: `12`

Use the signed application asset to verify managed deployment, ordered-command
failure handling and application trial confirmation. No core update is needed.
