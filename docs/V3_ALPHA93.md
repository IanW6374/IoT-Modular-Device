# IoT-MD v3.0.0-alpha.93

Release sequence: 2798. Native ABI: 6. Required runtime core API: 12.

Alpha 93 is an application-only test release for exercising multi-device
deployment progress in IoT-MD Management Suite 2.6.0. It intentionally carries
no native-core or configuration-schema change.

Use devices with different activation timing to confirm that every deployment
milestone shows its own completed-device count and percentage without earlier
milestones moving backwards.
