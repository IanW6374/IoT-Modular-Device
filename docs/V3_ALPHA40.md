# IoT-MD v3.0.0-alpha.40

Release sequence: 2745. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 40 is an application-only test release for exercising the signed upgrade
workflow from Alpha 39. It contains no intentional functional changes beyond
the product and runtime version increment, and retains Alpha 39's Upgrade-tab
