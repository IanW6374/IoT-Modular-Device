# IoT-MD v3.0.0-alpha.72

Release sequence: 2777. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 72 is a signed application-only dummy release for testing the upgrade
path from Alpha 71. It contains no intentional functional changes beyond the
product and runtime version increment.

Use this release to verify that IoT-MD Management Suite 2.2.20 refreshes and
matches the device signing-key fingerprint before submitting policy, and that
the device's Automatic method downloads and stages the update within the
existing Updates-page progress graph.

The application remains compatible with the Alpha 62 native core.
