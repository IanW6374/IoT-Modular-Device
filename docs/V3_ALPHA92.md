# IoT-MD v3.0.0-alpha.92

Release sequence: 2797. Native ABI: 6. Required runtime core API: 12.

Alpha 92 aligns live workflow behaviour with the Management Suite. Completed
update milestones use green ticks, while active steps retain their measured
percentage. Expanded disclosure panels now remain open when an asynchronous
form refreshes the surrounding page section.

This is an application-only update and does not change device configuration,
trust material or the native core.
