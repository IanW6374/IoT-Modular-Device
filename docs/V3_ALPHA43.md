# IoT-MD v3.0.0-alpha.43

Release sequence: 2748. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 43 makes the selected upgrade file or release visually prominent and
uses a destructive treatment for Discard. Manual and automatic verification
now load the authoritative staged state into the existing Upgrade page without
a page reload. Reopening the page retains the same chart-based presentation:
the selected release, Discard, verification result and restart action remain
attached to their respective workflow steps.
