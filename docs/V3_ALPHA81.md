# IoT-MD v3.0.0-alpha.81

Release sequence: 2786. Native ABI: 6. Required core API: 11.

Alpha 81 adopts the Management Suite activity timeline for device update
history, persistent health events and failed qualification-test retry evidence.
The presentation keeps timestamps, event names and supporting details aligned
and readable on desktop and mobile screens.

This is an application-only release and retains the Alpha 78 frozen core.
Install Alpha 78 universal first when upgrading from an older core.
