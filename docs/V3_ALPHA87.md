# IoT-MD v3.0.0-alpha.87

Release sequence: 2792. Native ABI: 6. Required runtime core API: 12.

Alpha 87 makes rejected universal updates recoverable from the main Updates
page. An incomplete sequential transport is displayed as an interrupted
release with a persistent Discard action. Any verified inner component remains
bound to the universal transaction and cannot be activated independently.

The universal package retains the firmware-first Core API 11 to 12 bootstrap
introduced in Alpha 86.
