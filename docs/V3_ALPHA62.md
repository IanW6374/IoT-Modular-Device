# IoT-MD v3.0.0-alpha.62

Release sequence: 2767. Native ABI: 6. MicroPython: 1.29.0. ESP-IDF: 5.5.5.

Alpha 62 is a signed dummy release for testing the upgrade path from Alpha 61
and then applying a reusable configuration profile from IoT-MD Management
Suite. It contains no intentional functional changes beyond the product and
runtime version increment.

The application remains compatible with the Alpha 61 native core. Complete
application, core and universal artifacts are published so the Management
Suite can verify, synchronize and promote the release through its normal
catalog workflow.
