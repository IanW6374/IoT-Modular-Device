# IoT-MD v3.0.0-alpha.79

Release sequence: 2784. Native ABI: 6. Required core API: 11.

Alpha 79 is a signed application-only dummy release for end-to-end testing of
an immediate deployment from IoT-MD Management Suite 2.2.23 to an Alpha 78
device. It contains no intentional functional change beyond the version and
runtime identifiers.

Install the Alpha 78 universal bundle first so the device has the frozen trial
confirmation fix and core API 11.
